# Workspace Rules

- Keep `README.md` and `docs/DESIGN.md` updated in the same change set as code changes.
- See `docs/README.md` "The standards" and `docs/DESIGN.md` for project conventions.
- Web applications and APIs adhere to strict CSP standards: JavaScript in `.js` files, CSS in `.css` files; no inline code.
- Include one blank line after each line of C# code in most cases.
- When changing a project, update its README or relevant docs in the same commit.
